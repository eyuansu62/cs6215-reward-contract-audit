# Public export

This repository derives from the local v3 reproduction archive and the separately revised manuscript. The manuscript includes the public repository link. The public copy retains the selected source, experimental code, inputs, prompts, model replies, witnesses, and recorded decisions.

Absolute workstation paths in text records appear as placeholders. Upstream metadata email fields were masked. The export omits raw transport diagnostics and workspace inventories, local presentation history, the bulk census tarball, and source copies from screened-out candidate projects. Commit references and screening metadata provide provenance for the omitted project sources.

[The export inventory](reproducibility/public-export.json) records the local archive digest and lists transformed and omitted files. [The public manifest](reproducibility/public-manifest.json) binds the bytes provided here. The original manifests and stage notes describe the local freezes. Their strict byte-level replay gates apply to that archive. The public verifier recomputes results from the published records.
