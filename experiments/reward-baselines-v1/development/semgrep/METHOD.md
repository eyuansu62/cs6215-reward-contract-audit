This baseline invokes the existing Semgrep CE 1.183.0 native search engine. It applies the same three authored rule families to every source-only unit: Boolean truthiness equality, `min(1.0, math.exp(-distance))`, and a ratio divided by the minimum of two string lengths. Unit IDs, source origin paths, contract IDs and version disposition do not choose rules or determine alarms. Contract IDs validate the frozen input clauses and are logged for audit. CPython AST validates the declared score/helper envelope and locates coverage spans; it does not remove risky findings using semantic reasoning. No scorer or helper code executes.

For the clamping rule, exact adjacent rejection guards of the form `if not math.isfinite(distance): return 0.0`, followed by an assignment or direct return of the clamp, are excluded by Semgrep patterns. An immediate positive `if math.isfinite(distance)` branch is also recognized. Only a bare distance variable receives these exclusions. A reassignment or intervening statement prevents exclusion. A finite check on a different variable or on a repeated call expression does not suppress a finding. Rebound builtin/math names, local imports, nested functions/classes and malformed metadata are unsupported and return Unknown. Aliases, equivalent arithmetic, more distant guards, componentwise finite guards and complex helper/dataflow equivalences are not modeled.

The Boolean equality rule deliberately does not prove surrounding semantic token/equality guards. A synthetically correct Boolean function with a semantic equality preguard followed by truthiness equality therefore still warns. A minimum-length ratio is a syntactic risky idiom: this rule does not prove that the numerator is a prefix counter or that the ratio reaches a full-reward return. All alarms are heuristic findings, not executable counterexamples.

Every successful run first obtains actual function and return matches from separate search-mode coverage rules. It checks every declared function name/definition end and every exact return span against the source AST, including helper returns. Missing coverage, parse/engine errors, skipped rules and timeouts yield Unknown. A completed scan with no warning is NoAlarm, not a proof of the supplied semantic contract. No dedicated palindrome/multiset or prime-factor/product semantics are implemented; C4/C5 NoAlarm outcomes must be described with this qualification. Legitimate positive partial rewards do not trigger warnings merely for being positive.

Audit outputs retain exact source UTF-8 bytes and hash, pinned engine version/hash, each command/return code, stdout/stderr, full raw engine JSON, both rule files and their hashes, all engine findings, scoped finding spans and coverage. Synthetic regressions include risky examples, straightforward finite guards, rebound/wrong/nonadjacent guards, partial rewards, helper/decorator/bare-return coverage, Unicode source and failures. Development runs are source-only synthetic fixtures; no curated probes, labels, issue/PR prose or primary predictions were used in these runs.
