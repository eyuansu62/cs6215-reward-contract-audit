# 独立布尔 reward 测试：数据准入结果

**这轮没有启动 LLM／基线独立测试。** 保持原 True/False 显式义务接口、排除已见任务和重复评分实现后，没有组成至少两个函数的合格小批样本。新增工作是源码准入筛选与同快照结构普查，所有既有方法和冻结结果保持原值。没有把排除项凑成测试集，也没有将未测指标填写为 0。

## 固定条件

继续使用 Reasoning Gym 提交 `49b07130b3fcd12f2d064bba7c43869543a0e7e7`。候选必须满足：题目内容此前未读、原生答案／参考兼容 True/False、有自有真实 `score_answer`，且实现不与已见代码或本批其他函数重复。先前筛掉的任务、普通对照和默认继承评分器也都进入暴露排除表。

计划固定复用上一轮提示、schema、分析环境、v2 义务接口、Semgrep 和纯符号模块，不改变 token 编码、字段绑定、Python 操作或模型提示。相关文件摘要在 [planned-comparison.json](planned-comparison.json) 中逐项记录。新文件名不等于新评分实现；也不能把原生 0/1 或 Yes/No 改写成 True/False 后称为原接口上的真实独立测试。

## 八个概念候选

最初按题名选择六个可能的逻辑／归纳布尔任务，上限八个；在看到模型、分析器或奖励结果之前完成准入，随后用了剩余两个名额。两个阶段的计划、结果和冻结清单均保留。

| 候选 | 实际答案域 | 评分实现情况 | 排除原因 |
|---|---|---|---|
| syllogisms | Yes/No | 继承已见默认 scorer | 编码不兼容且实现重复 |
| circuit_logic | 0/1 字符串 | 有自有 scorer | 编码不兼容 |
| self_reference | 满足条件的解的数量 | 有自有 scorer | 不是布尔回答 |
| propositional_logic | 逻辑结论表达式，参考字段为 None | 有自有 scorer | 不是单个布尔 token／规范参考 |
| knights_knaves | 人名与角色分配集合 | 有自有 scorer | 不是单个布尔回答 |
| ACRE | on/off/undetermined | 继承已见默认 scorer | 三值编码且实现重复 |
| aiw | 人数计数 | 继承已见默认 scorer | 不是布尔回答且实现重复 |
| binary_alternation | 最小交换次数或 -1 | 继承已见默认 scorer | 不是布尔回答且实现重复 |

八项均未纳入。该结论有原生 `entry.answer` 表达式、题目及评分器是否覆写的源码证据，不是用分析器表现筛出的排除项。

## 同一快照的结构普查

为避免仅凭八个文件名就得出过强结论，在没有任何模型／分析器结果时，追加并单独冻结了同一提交的数据可得性普查。它扩展源码整理范围，不扩展分析器。原八项结果没有被覆盖。

固定提交归档约 8.6 MB。按预先记录的范围纳入 122 个 Python 文件，排除 vendored contrib、rearc 工具／生成器、数据、包初始化等 65 个文件。全部纳入内容逐个与固定树的 Git blob SHA1 及 SHA256 核对，并仅解析 AST，没有执行上游代码。

纳入文件中有 108 个顶层名称以 Dataset 结尾的类，其中 75 个自有 `score_answer`。这些数字包含基类／组合类，不是 108 个独立已注册任务或 75 个可用布尔函数。还记录了这 108 个类的答案字段／赋值／直接 producer 线索。

非 scorer 字符串的 True/False/Boolean 线索命中了 13 个类。直接复核后，支持原生规范 True/False 任务的已知四类为：

| 类 | 是否已见 | scorer |
|---|---|---|
| GameOfLifeHalting | 已见、已用于开发闭环 | 自有，已评测 |
| IsomorphicStrings | 已见 | 继承已见默认函数 |
| RansomNote | 已见 | 继承同一个默认函数 |
| CourseSchedule | 已见 | 继承同一个默认函数 |

其他文本命中主要来自内部验证器文档或布尔配置参数，不意味着答案域为 True/False；答案字段结构线索也未识别出额外合格候选。**这是对记录范围的源码筛查结果，不是对整个项目任意运行时路径的完备域证明。** 没有执行任务生成器来证明所有动态返回域，也没有把启发式线索等同于语义验证。

另核对了当前公开 main 的提交／文件树元数据，主线已经不同于固定提交，但没有新增 Python 路径；没有抓取或纳入新主线完整源码，也没有更换版本。补充公开检索出现过 countdown 的未固定主线代码片段及其他不兼容接口片段，已[单独记录](audit/additional-source-exposure.json)，未用于固定快照的准入结论。不能据文件树元数据断言新主线实现与固定版本完全相同。

## 去重与暴露记录

保留了原始源码和完整 AST 摘要。初版辅助 alpha 指纹把全局名也重命名，可能错误合并 `bool` 与 `str` 等不同调用；审查指出后，该字段明确降为未用于纳入的诊断数据，未改写已经封存的旧阶段。追加的保守指纹只重命名词法局部变量／参数，保留全局、内置及属性名称。

无注解／文档字符串 AST 和局部 alpha 指纹只是实现去重线索，不是语义等价证明；真正纳入时还需要核对委托调用／helper 闭包。本次没有合格样本，因此该指纹问题没有改变任何纳入结果。

全部下载／解析的来源、排除理由、固定提交与主线元数据分别留档。122 个提取源码文件已成为后续任务的暴露内容；归档还保存了未逐条审阅的其他文件，不能在未来不核查便称其为全新素材。模型预训练的新颖性始终未知。
