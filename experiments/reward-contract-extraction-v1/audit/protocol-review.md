# Pre-model protocol review

Passed for the bounded six-template, description-only pilot. No blocking findings remain. This is an AI-assisted researcher-reference comparison, not a real-human annotation or time-saving experiment.

The six reference contracts were independently checked against only their descriptions and generic schema. All six are schema-valid; all evidence quotes are exact substrings. Boolean token semantics, occurrence multiplicity, prerequisite direction, inclusive prime endpoints, numeric sorting with string elements, and lowest-terms fraction semantics are preserved. Unstated case/whitespace normalization, tolerance and partial-credit allocation are not invented. The per-task rubric is included in the extraction freeze.

The request builder supplies only opaque task ID, question description, placeholder notes and generic output schema. It uses fresh ephemeral CLI sessions and temporary working directories, disables user config/project documentation, rejects tool/action events, validates responses, and preserves failures. The old baseline integrity check passes. Actual request-event logs and model identity still require runtime inspection.

Independent verification: 5 protocol tests passed, plus all six reference schema/exact-quote checks. Two narrow pre-freeze issues were resolved: reject nonfinite JSON numbers, and bind the comparison-rubric file into the freeze. No evaluated model outputs, scorer bodies, generator fragments, issues, hidden answers or target execution were consulted.

The downstream design conservatively projects only eligible native canonical True/False tasks to the unchanged existing Boolean necessary condition. Non-Boolean contracts remain unsupported. This does not validate the task's solver or the complete inferred contract; the actual bridge and source preparation need their own checks.

Field revisions must be semantic, substantive edits; synonyms, harmless elaboration and serialization differences alone are not errors. The count is a review-burden proxy, with no randomized human study or measured time data. Six purposive templates, known filenames, possible pretrained exposure and AI-assisted reference biases limit interpretation. Equal projections or detector verdicts do not establish improved detection. Only separately adjudicated labels justify TP/FP/FN/TN.
