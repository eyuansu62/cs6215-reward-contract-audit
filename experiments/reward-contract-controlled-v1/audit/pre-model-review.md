The expected matrix audits only a necessary condition of full credit. It does not establish complete reward-policy correctness: equality can under-reward the opposite valid label under V, and the literal token-only program can under-reward permitted case or whitespace variations. A no-alarm result is therefore limited to the selected implication.

The central witness trap is handled explicitly. Under gold V, truthiness has a real full-credit violation on a non-Boolean string such as `banana`. But a wrong E-only extractor can return the witness `False` against reference `True`: that violates equality while satisfying V. The evaluator records whether each returned witness violates the gold predicate and excludes this coincidental positive from witness-supported detection gain. It reports extra unjustified witnesses separately, even when another witness is valid.

The transport sends only the description, an opaque administrative ID, empty notes and the fixed profile. It uses an ephemeral directory, disables project documents and user configuration, and applies the unchanged schema/validator and event audit. Tool/action traces are rejected. No contract obligation is inserted, removed or repaired. A failed or rejected attempt with partial JSON is retained as INVALID; it does not abort the remaining comparison or become a correct U.
